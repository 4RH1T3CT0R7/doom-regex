# doom-regex

**DOOM на регулярных выражениях**: компьютер, в котором единственный шаг вычисления — глобальная regex-подстановка (find/replace-all) над одной строкой-состоянием, повторяемая в цикле. Итеративная подстановка ≡ алгоритмы Маркова ≡ Тьюринг-полнота. См. [HONESTY.md](HONESTY.md) — правила честности проекта.

## Дорожная карта

- **Этап 0 (PoC):** интерпретатор Brainfuck как набор правил подстановки; драйвер не знает о BF ничего. ← *текущий*
- **Этап 1 (MVP):** RegexVM (RVM-1) — 32-битная RISC-подобная CPU на правилах подстановки + ассемблер + бэкенд ELVM (C-компилятор) + Tetris.
- **Этап 1.5:** Bad Apple, вычисляемый подстановками.
- **Этап 2:** DOOM через doomgeneric — offline timedemo (~часы на кадр, и это фича) + интерактивное слайд-шоу.

## Структура

```
vm/        ISA, ассемблер, референс-эмулятор, генератор правил (Python)
proto/     Python-драйвер цикла подстановок (модуль regex) — прототип/отладка
driver/    Продакшн C-драйвер (PCRE2, LINK_SIZE=4, JIT)
viz/       Визуализатор фреймбуфера (pygame-ce)
tests/     Дифф-тесты против референс-эмулятора, golden-трейсы, fuzz
bench/     Перф-харнесс и baseline
scripts/   Сборка/запуск/трейс (PowerShell + Python)
research/  Исследование и исправленные цитаты
```

## Запуск (Windows)

Python — только через `py -3.11` (заглушка `python` в PATH не работает). Сборки и артефакты уходят в `%DOOMREGEX_OUT%` (по умолчанию `C:\dev\doom-regex-out`) — репозиторий в OneDrive, тяжёлые файлы там не живут.

```powershell
py -3.11 proto/driver.py --rules gen/hello_bf.rgxset --state gen/hello_bf.rvstate
```

## Почему это ново

Прецеденты: BF-интерпретаторы на find/replace (Tegmen), машина Тьюринга в Notepad++ (0xdanelia), esolang «Iterated regex» (доказательство Тьюринг-полноты — LyricLy). Ближайшая родственная работа — Regex Chess Н. Карлини (2025): 84 688 подстановок, но **фиксированная развёрнутая последовательность без циклов** (сам автор подчёркивает не-Тьюринг-полноту). Doom через ELVM уже загоняли в Brainfuck (BFDoom), но **никто не исполнял игру итеративным Тьюринг-полным циклом regex-подстановок**. Этот проект делает ровно это.
